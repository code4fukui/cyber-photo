# cyber-photo

> 日本語のREADMEはこちらです: [README.ja.md](README.ja.md)

A simple web tool to apply a neon "Cyber Friday" text overlay to your photos.


![cyber-photo demo showing an image of a city at night with a neon green "Cyber Friday" text overlay.](https://code4fukui.github.io/cyber-photo/cyber-photo.png)


## Demo

Try it live: **[https://code4fukui.github.io/cyber-photo/](https://code4fukui.github.io/cyber-photo/)**

## Features

-   **Drag & Drop Interface:** Simply drop one or more image files onto the web page.
-   **Cyber-Style Overlay:** Automatically adds a rotated, neon-green "Cyber Friday" text effect to each image.
-   **Automatic Downloads:** Your processed image or images are downloaded immediately after processing.
-   **Batch Processing:** Handles multiple images at once and conveniently packages them into a single ZIP file.

## Usage

1.  Navigate to the [demo page](https://code4fukui.github.io/cyber-photo/).
2.  Drag and drop one or more image files from your computer onto the main area of the page.
3.  The tool will process the images and display the results. The download will start automatically.
    -   If you drop a **single image**, it will be downloaded as an image file.
    -   If you drop **multiple images**, they will be downloaded as a `cyberphoto.zip` archive.
4.  Click on any processed image on the page to view it in full-screen mode.
