# cyber-photo

写真にネオン調の「Cyber Friday」テキストを重ね合わせるシンプルなWebツールです。

![cyber-photoのデモ。夜の街の画像にネオングリーンの「Cyber Friday」テキストオーバーレイが表示されています。](https://github.com/code4fukui/cyber-photo)

## デモ

こちらでお試しいただけます: **[https://code4fukui.github.io/cyber-photo/](https://code4fukui.github.io/cyber-photo/)**

## 機能

-   **ドラッグ＆ドロップ操作:** Webページに1つ以上の画像ファイルをドラッグ＆ドロップするだけです。
-   **サイバー風オーバーレイ:** 各画像に、斜めに配置されたネオングリーンの「Cyber Friday」テキストエフェクトを自動的に追加します。
-   **自動ダウンロード:** 画像の処理が完了すると、自動的にダウンロードが開始されます。
-   **一括処理:** 複数の画像を一度に処理し、1つのZIPファイルにまとめてパッケージ化します。

## 使い方

1.  [デモページ](https://code4fukui.github.io/cyber-photo/)にアクセスします。
2.  PCから1つまたは複数の画像ファイルを、ページのメインエリアにドラッグ＆ドロップします。
3.  ツールが画像を処理し、結果を表示します。その後、ダウンロードが自動的に開始されます。
    -   **1つの画像**をドロップした場合は、そのまま画像ファイルとしてダウンロードされます。
    -   **複数の画像**をドロップした場合は、`cyberphoto.zip`というZIPファイルにまとめられてダウンロードされます。
4.  ページ上の処理済み画像をクリックすると、フルスクリーンモードで表示されます。
